# API Productos — ejemplo transversal

Proyecto pequeño para observar juntos:
- REST;
- DTO;
- validación;
- service;
- JPA;
- errores;
- JUnit/Mockito;
- MockMvc;
- Maven;
- Docker.

## Ejecutar
```bash
mvn spring-boot:run
```

## Probar
```bash
mvn test
```

## Empaquetar
```bash
mvn package
```

La base H2 en memoria es intencional para este ejemplo didáctico. No representa una configuración de producción.
