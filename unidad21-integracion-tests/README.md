# Unidad 21 — Pruebas de integración

## Objetivo
Comprobar colaboración real entre varias capas.

## @SpringBootTest
Carga un contexto amplio; úsalo cuando ese alcance aporta valor.

## Web
Puede combinarse con cliente de pruebas según escenario.

## Datos
Los tests deben ser reproducibles y aislar estado.

## Pirámide práctica
No necesitas una proporción dogmática, pero evita que toda verificación dependa de pruebas lentas de extremo a extremo.

## Reto
Prueba creación→persistencia→consulta de un recurso.
