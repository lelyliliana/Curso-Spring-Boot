# Unidad 30 — Proyecto final

Construye una API backend completa.

## Requisitos
- Java 21;
- Spring Boot 3.x;
- Maven;
- DTO;
- validación;
- errores globales;
- capas claras;
- JPA;
- migraciones;
- pruebas;
- seguridad apropiada al caso;
- Actuator;
- métricas/logging;
- configuración externa;
- Docker;
- README reproducible.

## Opcional según problema
- API externa;
- tareas programadas;
- resiliencia;
- carga/rendimiento.

## Regla
No añadas tecnologías solo para cumplir una lista. Si un requisito no aplica, documenta y justifica.
