# Unidad 24 — Métricas y observabilidad

## Métricas
Contadores, gauges, timers y distribuciones permiten observar comportamiento agregado.

## Micrometer
Proporciona una fachada de instrumentación para distintos backends.

## Métrica útil
Debe responder una pregunta operacional.

Ejemplos:
- latencia;
- tasa de errores;
- solicitudes;
- uso de recursos.

## No uses identificadores únicos como tags
Puede provocar cardinalidad explosiva.

## Reto
Define cinco métricas para una API y explica qué decisión permite cada una.
