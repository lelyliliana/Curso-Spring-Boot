# Unidad 23 — Actuator y health checks

## Actuator
Expone endpoints operativos.

Ejemplos:
- health;
- info;
- metrics.

## Health
“UP” no significa que cada caso de negocio funcione. Define dependencias relevantes.

## Exposición
No publiques todos los endpoints de Actuator sin evaluar información sensible.

## Reto
Configura health e info y decide qué endpoints deben estar expuestos.
