# Diagnóstico Spring Boot — Por capas

## 1. Maven/compilación
Dependencias, Java, errores de compilación.

## 2. Contexto Spring
Beans, configuración, perfiles.

## 3. HTTP
Ruta, método, status, JSON.

## 4. Validación/dominio
¿La regla rechaza o acepta correctamente?

## 5. Persistencia
SQL, constraint, transacción, relación.

## 6. Integración externa
DNS, conexión, timeout, status, parseo.

## 7. Seguridad
Autenticación, autorización, CORS/CSRF según contexto.

## 8. Operación
Health, métricas, logs, recursos.

## Regla
“Spring no funciona” no es un diagnóstico. Identifica la capa y conserva evidencia.
